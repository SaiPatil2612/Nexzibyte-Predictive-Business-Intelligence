# NexziByte Predictive Business Intelligence & Growth Engine

A 15-working-day predictive business intelligence project.

## Project structure
- data: source, cleaned, synthetic and dictionary data
- sql: schema, data-quality checks and analytical views
- src: ingestion, feature engineering, models, forecasting, recommendations and anomaly detection
- notebooks: profiling, EDA, features and model experiments
- models: saved model artifacts
- api: API prototype
- powerbi: dashboard files
- reports: analysis and final reports
- tests: project tests
- docs: project charter, KPI dictionary and process map
